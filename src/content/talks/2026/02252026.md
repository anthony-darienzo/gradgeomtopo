The slogan for "lasagna" (the skein lasagna modules) is: whenever we have a link
TQFT, we can use it to cook an invariant for 4-manifolds. This invariant is best
established by Morrison-Walker-Wedrich when Khovanov(-Rozansky) homology is
used, which is proved to detect some exotic pairs of smooth 4-manifolds and some
exotic surfaces in a 4-manifold. The case when the TQFT is the link Floer
homology is also established by Chen, but has not yet been studied in depth. In
this talk, I'll describe the machine to build lasagna invariants from link
TQFTs, several ideas on further research, and, if time permits, the 2-handlebody
formula (the case when the lasagna invariant is most computable).

I'm quite interested in lasagna theory (and I'm actually working on a project
right now), so if anyone feels the same, I'm happy to talk, and we could even
collaborate on some project!
